# Privacy and distribution boundaries

This repository contains the Discord DVR source adaptation, tests, and documentation. It does not contain the proprietary Discord IPA, the original Drover packet, user call recordings, device signing credentials, or private diagnostic logs.

## Runtime

The 0.3.1 release-mode DVR library adds no analytics endpoint, microphone recorder, packet capture, diagnostic UI, or continuous NDJSON logging. This statement describes only the DVR adaptation and does not certify the behavior of the third-party Discord app or signing software.

## Sideloading

Sign any authorized IPA using **your own Apple ID** in Sideloadly. Trust/provisioning profiles generated by your signing tools may display your account email and device identifiers. Do not post those files or unredacted screenshots.

## Development

Use a GitHub `noreply` commit author address. A private repository's commit history, workflow logs, and artifacts may become visible if its privacy setting is changed. Do not simply publish old development repositories containing private builds.

Do not upload private Discord app binaries, upstream packet bytes, credentials, raw logs, or personal account information to this source repository. Verify redistribution rights before publishing third-party materials.
